NexPharma Dashboard

This dashboard updates automatically when new data is added.

Quick Start:

1. Export the latest data from Zoho using the saved export templates
2. Save the exported files into:
   Data_Input/01_raw/
3. Open NexPharma_Dashboard.pbix
4. Click Refresh
5. Save the PBIX file

Documentation:

* Data_Update_Guide.txt = how to replace files and refresh
* Zoho_Export_Guide.txt = which Zoho fields and templates to export

Important:

* Do not move or rename this folder
* Do not rename the exported files
* Do not change the column structure
